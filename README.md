# 📊 HR Analytics & Workforce Retention Dashboard

An interactive multi-page Power BI dashboard built to analyze employee demographics, departmental headcount, attrition drivers, attendance trends, and internal career progression. Designed to help HR teams identify turnover risks, monitor workforce presence, evaluate promotion fairness, and make data-driven talent decisions.

## 🎯 Key Business Questions Answered
* **Workforce Distribution:** How is headcount distributed across departments, job roles, and locations?
* **Attrition & Retention:** What is the overall attrition rate, which departments or tenure groups experience the highest turnover, and what factors drive employee exits?
* **Attendance & Absenteeism:** What are the overall attendance rates, absenteeism trends, and leave patterns across departments and work shifts?
* **Promotion & Career Growth:** Which departments and job levels have the highest promotion rates, and how long do employees wait between promotions?
* **Demographics & Diversity:** What is the breakdown of employees, retention, and promotions across age groups, gender, and education levels?

---

## 🛠️ Tools & Technical Skills Demonstrated
* **Power BI Desktop:** Multi-page interactive report design, custom visual formatting, drill-through pages, and dynamic slicers.
* **Power Query (ETL):** Data cleaning, handling missing values, data type standardization, and column transformations.
* **Data Modeling:** Star-schema relationships and custom date/calendar tables for time-intelligence analysis.
* **DAX (Data Analysis Expressions):** Custom calculated measures for Attrition Rate %, Retention Rate %, Attendance %, Absenteeism Rate %, Promotion Rate %, Average Tenure, and KPI variance indicators.

## 🚀 How to View This Project
1. Download the `.pbix` file from this repository.
2. Open it using **Microsoft Power BI Desktop** (free to download).
3. Use the interactive slicers (Department, Gender, Age Group, Job Role, Date) to filter and explore insights across all four report pages.
